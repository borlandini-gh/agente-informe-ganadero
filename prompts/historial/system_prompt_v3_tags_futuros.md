# Versión 3 — contrato aprobado

## Pieza modificada: Formato

El template usa cuadros de texto independientes y un CSV de una fila. Los meses futuros deben verse vacíos en el informe, pero Canva no mostraba inicialmente como vinculables los campos completamente vacíos.

Los tags futuros se vincularon una sola vez durante la configuración del template. El contrato final conserva sus encabezados y entrega valores realmente vacíos hasta que exista el dato. También se separó la fecha corta de auditoría del texto completo de notas al pie.

La prueba final de julio de 2026 produjo 126 campos, pasó C01–C11 y fue revisada página por página antes de quedar lista para la corrección final de Cachu.
